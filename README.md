# سعاد محتسب | مساحة دعم

موقع عربي RTL تجريبي مبني كواجهة ثابتة متوافقة مع GitHub Pages.

## النشر
- المستودع: `waleedfouleh-source/Suad_muhtaseb`
- ملف الموقع الرئيسي: `index.html`
- دليل الخدمات والبرامج: `services.html` (تصنيفات مبدئية؛ الأسعار والمدد وطرق التقديم قيد الاعتماد من سعاد)
- يوجد GitHub Actions workflow في `.github/workflows/pages.yml` للنشر التلقائي على GitHub Pages عند الدفع إلى فرع `main`.

من إعدادات المستودع، تأكد من تفعيل Pages واختيار GitHub Actions كمصدر للنشر. بعد نجاح أول عملية نشر سيظهر رابط الموقع في Settings → Pages وفي نتيجة الـ workflow.

## قبل الإطلاق الرسمي
- اعتماد النبذة المهنية والخدمات من سعاد.
- تعبئة تفاصيل كل خدمة في دليل الخدمات: الاسم النهائي، الوصف، الجمهور المناسب، طريقة التقديم، المدة، السعر/الباقات، المواعيد، وسياسة الإلغاء إن وجدت.
- إزالة أي تصنيف غير مناسب وإضافة جميع الخدمات التي تؤكد سعاد أنها تقدمها.
- إضافة وسيلة التواصل الرسمية والأسعار وآلية الحجز.
- مراجعة سياسة الخصوصية وشروط الخدمة.
- ملاحظة: نموذج التواصل في النسخة الحالية لا يرسل بيانات إلى خادم ولا يخزنها؛ ينشئ رسالة محلية فقط.
- لا توجد قاعدة بيانات أو تسجيل دخول في هذه النسخة. عند الحاجة، اربط مشروع Supabase مستقلًا بعد إعداد الجداول وسياسات RLS ومراجعتها.
