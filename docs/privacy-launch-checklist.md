# قائمة مراجعة الخصوصية والأمان قبل إطلاق منصة سعاد محتسب

**الحالة: لا تستقبلوا بيانات حقيقية حساسة قبل إكمال البنود الحرجة ومراجعة محامٍ مختص.**

## قرارات قانونية لازمة
- [ ] تحديد الدولة/الدول التي ستُقدَّم فيها الخدمة ومكان المستخدمين المستهدفين.
- [ ] تحديد الاسم القانوني وصفة مقدم الخدمة، ومن يحدد أغراض معالجة البيانات.
- [ ] مراجعة محامٍ مختص لقانون الخصوصية، البيانات الحساسة، السجلات المهنية، حماية المستهلك، والتزامات الإبلاغ عند الحوادث.
- [ ] اعتماد اتفاقية مكتوبة بين سعاد ومالك/مدير المنصة: الأدوار، الملكية الفكرية، السرية، حدود الوصول، المسؤولية، الحوادث، إنهاء التعاون، وتسليم/حذف البيانات.
- [ ] اعتماد سياسة الخصوصية وشروط الاستخدام وموافقة منفصلة مستنيرة إذا كانت الخدمة المهنية تتطلب ذلك.
- [ ] تحديد وسيلة رسمية لطلبات الخصوصية والشكاوى.
- [ ] تحديد مدة الاحتفاظ والحذف لكل نوع بيانات.

## ضوابط تقنية قبل استقبال أي ملف
- [ ] عدم تفعيل قاعدة بيانات أو تسجيل دخول قبل تصميم ومراجعة نموذج التهديد والصلاحيات.
- [ ] إذا استُخدم Supabase: تفعيل RLS لكل جدول يحتوي بيانات مستخدمين، وكتابة اختبارات تمنع الوصول بين المستخدمين، وعدم وضع service-role key في المتصفح أو مستودع GitHub.
- [ ] استخدام MFA للحسابات الإدارية، وأقل صلاحية لازمة، ومراجعة دورية للصلاحيات.
- [ ] عدم إرسال النصوص الحساسة إلى خدمات الذكاء الاصطناعي أو التحليلات قبل مراجعة اتفاقية المزود وسياسة الاحتفاظ ومكان المعالجة.
- [ ] تحديد سياسة سجلات لا تسجل محتوى الاستشارات أو الأسرار، وتحديد مدة الاحتفاظ بالسجلات.
- [ ] تشفير النقل والتخزين، وتحديد النسخ الاحتياطية واختبار استعادتها إذا أضيف تخزين.
- [ ] إعداد خطة استجابة للحوادث، وتحديد من يتصرف وكيف يتم الإبلاغ وفق القانون.
- [ ] اختبار أمان مستقل قبل الإطلاق، بما في ذلك التحكم بالوصول، XSS، CSRF حيث ينطبق، وإدارة الجلسات.
- [ ] اختبار مسار حذف البيانات والنسخ الاحتياطية.
- [ ] إزالة أي بيانات تجريبية حقيقية من المستودع والموقع.

## الوضع الحالي بحسب الكود
- الموقع واجهة ثابتة منشورة عبر GitHub Pages.
- التقييم الأولي يعرض توجيهًا عامًا بقواعد داخل المتصفح؛ لا يوجد إرسال لإجابات التقييم إلى قاعدة بيانات في النسخة الحالية.
- نموذج التواصل ينشئ رسالة محلية للنسخ ولا يرسلها تلقائيًا.
- لا توجد حاليًا قاعدة بيانات أو حسابات مستخدمين ضمن النسخة التي تمت مراجعتها.
- أُضيفت مسودتا سياسة الخصوصية وشروط الاستخدام وإقرار قبل التقييم ونموذج التواصل. هذه إضافات تحضيرية وليست اعتمادًا قانونيًا أو ضمانًا للامتثال.

## شرط الإطلاق
لا تستقبلوا ملفات نفسية أو أسرية حقيقية ولا تفعّلوا حفظها قبل إكمال البنود القانونية الحرجة، ومراجعة محامٍ، ومراجعة تقنية للبيئة الفعلية.
